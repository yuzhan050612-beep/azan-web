# 阿赞 Henry · 作品集发布

本仓库沿用已绑定域名的 Vercel 项目 `azan-web`，生产分支为 `main`。

`release/` 保存经过核验的静态网站发布包。Vercel 执行 `node scripts/assemble.mjs`，逐块校验 SHA-256，依次还原基础包与清单中的增量更新到完整 `dist/`，只发布该目录。无需安装依赖。旧版无更新包的清单仍受支持。

完整可编辑网站及检查脚本备份在账号内的私有仓库 `azan-portfolio`。发布包包含 21 个 HTML 页面和全部图片、动画与脚本，包括骑手端安全等级详情页与 Qwen-Image 工作流文章。

更新时先生成新的发布包和清单，在预览分支确认部署成功后，再合入 `main`。
2026-11-13 最终版清理了不参与发布的演示站入口、React/Vite 代码与依赖；原文件保存在 Git 历史及本地归档中。`npm run build` 与 Vercel 均执行同一还原脚本，每次先清理生成目录，再核验归档及文件数量，避免重复构建残留旧文件。现有域名、Git 集成和历史部署继续保留。
