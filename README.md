# 阿赞 Henry · 作品集发布

本仓库沿用已绑定域名的 Vercel 项目 `azan-web`，生产分支为 `main`。

`release/` 保存经过核验的静态网站发布包。Vercel 执行 `node scripts/assemble.mjs`，逐块校验 SHA-256 后解包到 `dist/`，只发布该目录。无需安装依赖。

完整可编辑网站及检查脚本备份在账号内的私有仓库 `azan-portfolio`。发布包包含 19 个 HTML 页面和全部图片、动画与脚本。

更新时先生成新的发布包和清单，在预览分支确认部署成功后，再合入 `main`。
原演示站的根目录文件保留在仓库及历史记录中，方便回退。
